# YBDD2.0 · FR-021 2.0优化 — Epic Breakdown

## Overview

本文是 FR-021 的史诗与故事，按 2026-10-21 修订后的合同整份重写。增量内的 `FR-n` 是本 PRD 的能力编号；迭代全局编号是 **FR-021**。

输入以这三份为准：

- PRD `prds/prd-YBDD2.0-2026-10-07/prd.md`（updated 2026-10-21）
- 体验合同 `ux-designs/ux-YBDD2.0-2026-10-07/EXPERIENCE.md`
- 架构 `architecture/architecture-fr021-YBDD2.0-2026-10-07/ARCHITECTURE-SPINE.md`

同一 UX 目录的 `DESIGN.md` 只提供视觉 token。它和 PRD 冲突时，按 DESIGN 自己的冲突规则，以 PRD 为准。已确认的一处冲突：DESIGN 写金刚区标题固定，PRD D-14 与 EXPERIENCE 写入口来自后台「金刚区配置」。故事按可配置交付，视觉仍用 `shortcut-grid`。

架构脊的 `updated` 仍是 2026-10-07，binds 还写着 FR-1..19、epic-1..7 和「学院中心」。与 2026-10-21 的 PRD 冲突时，以 PRD 和 EXPERIENCE 为准。因此：

- 不实现今日路径。spine 的 AD-4 作废。
- 用户可见名是「商学院」，不再使用「学院中心」。
- 完课口径是图文正文最后一块、视频播放 ≥90%。spine AD-2 里的「图集最后一张」作废，单一计算点这条规则保留。
- 本文件的史诗编号是这次重排的，不能对回 spine 里的旧 Epic 1–7。

没有 starter template。生产沿用现网 App 和学院后台。本仓库只交付迭代 Demo，不从脚手架初始化项目。

FR-22: 后台「新手学院」菜单含新手课程、新手项目、新手关键词、客服。C 端只读这些配置。本菜单不写学习数据。

### NonFunctional Requirements

```
NFR1: 首页减噪走查一次通过率 ≥90%（SM-1）。清单含学习卡/活动卡、金刚区四入口、榜单 TOP3、动态 2 条、找项目布局。
NFR2: 图文正文末块与视频 ≥90% 在 C 端进度和后台学习数据之间抽样零冲突（SM-2）。
NFR3: 数据 Tab 示例数据不代表真实收益、不计入账户，且能退出演示回到空态。
NFR4: #dataPage 黑金样式不得污染首页、变现页或其他 Tab。
NFR5: 首页项目 chips 不得套用变现页 .project-tools 的 grid。
NFR6: 金刚区每个入口的无障碍名称等于可见标题。Sheet 关闭钮有 aria-label。收益信息除颜色外还有字重或字号。
NFR7: 新手学院不写学习进度，不进入商学院学习数据。
NFR8: 学习进度上报幂等。失败可重试，不因单次失败永久丢掉完课进度。
```

SM-3（工具 Sheet 使用率）和 SM-4（三个金刚区入口零新建页）是上线后指标。SM-C1 要求活动轮播变多时，学习卡进商学院的路径仍然一眼能认。它们不单独建故事，由 FR-6、FR-20、FR-2 的验收覆盖。

## Epic 1: 商学院学习

创作者在商学院按频道学习。这一史诗不依赖后面的首页或后台故事；现网已有课程即可按新详情展示。后台如何写入这些课，在 Epic 5。

### Story 1.1: 按频道浏览商学院

As a 创作者,
I want 在标题为「商学院」的页面按频道找课，并看到我的学习和收藏,
So that 我知道该学什么，也找得回学过的课。

**Acceptance Criteria:**

**Given** 已登录创作者打开商学院
**When** 页面出现
**Then** 页标题是「商学院」
**And** 底栏隐藏；返回首页后底栏恢复
**And** 频道为项目教学、案例拆解、进阶技巧、我的学习
**And** 列表只含已上架、且所属分类为启用的课
**And** 「我的学习」不来自后台分类

**Given** 创作者切换频道
**When** 选中项目教学、案例拆解或进阶技巧
**Then** 列表按该频道过滤
**When** 选中我的学习
**Then** 能看到最近学习和我的收藏，并看到进度百分比和继续学习

**Given** 新人条正在展示
**When** 创作者关闭它
**Then** 当前会话不再展示该条

*Fulfills FR-10, AD-6*

### Story 1.2: 阅读图文课并记完课

As a 创作者,
I want 把图文课从头读到正文最后一块，并在文末看到推荐课,
So that 系统知道我读完了，而不是把推荐区算进完课。

**Acceptance Criteria:**

**Given** 一门已上架图文课
**When** 创作者打开详情
**Then** 顶部展示标题、分类、类型和简介，类型可见名是「图文课程」
**And** 其下是不限高的正文，段落与 16:9 通栏图交替，页面向下滚动
**And** 不使用横滑图集、张数角标、步骤蒙层，也不把正文卡在播放器固定高度里
**And** 正文约 15px、行高 1.75、色 `#3d4c63`；通栏图圆角 8px
**And** 详情页没有底栏

**Given** 创作者把正文最后一块读进视区
**When** 进度上报成功
**Then** 进度服务把该课记为完课
**And** 文末推荐课程区不计入完课
**And** 上报键为 userId、courseId、clientReportId；乱序时保留更大的阅读位置
**And** 上报失败可以重试，不因一次失败永久丢掉进度

**Given** 同分类还有其他已上架课
**When** 创作者滚过正文
**Then** 推荐课程出现在详情最底部
**And** 没有可推荐课时保留空态，空态也不算完课

**Given** 创作者收藏或取消收藏
**When** 切换收藏
**Then** 我的收藏随之更新

**Given** 创作者离开后再打开同一图文课
**When** 详情加载
**Then** 恢复上次阅读位置
**And** 返回顺序是详情、商学院、首页

*Fulfills FR-11, UX-DR9, NFR2, NFR8, AD-2*
